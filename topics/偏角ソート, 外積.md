外積（cross product）は、最初に「2つのベクトルから新しいベクトルを作る演算」と説明されることが多いですが、競技プログラミングの2次元幾何では、むしろ次のように捉えた方が直感的だと思います。

外積は、2つのベクトルが作る平行四辺形の「符号付き面積」を求める演算である。

この解釈だけで、競プロで外積を使う場面のかなりの部分を理解できます。

## 1. 外積の絶対値は平行四辺形の面積

2つのベクトル

$\boldsymbol a=(a_x,a_y),\quad \boldsymbol b=(b_x,b_y)$

を考えます。

2次元の外積を

\[ \operatorname{cross}(\boldsymbol a,\boldsymbol b) =a_xb_y-a_yb_x \]

と定義します。

平行四辺形の面積は、底辺 × 高さなので、

\[ S=|\boldsymbol a|h \]

です。

ここで、2つのベクトルのなす角を \(\theta\) とすると、

\[ h=|\boldsymbol b|\sin\theta \]

なので（\(0\le\theta\le180^\circ\)）、

\[ \boxed{S=|\boldsymbol a||\boldsymbol b|\sin\theta} \]

となります。

実は、この値は外積の絶対値と一致します。

\[ \boxed{ S=|a_xb_y-a_yb_x| } \]

つまり、外積の絶対値は、2つのベクトルがどれだけ平面的に広がっているかを表しています。

例えば、ベクトルが平行であれば平行四辺形は潰れて面積0になり、直交していれば面積は最大になります。

## 2. 外積の符号は「回転の向き」を表す

では、外積に正負の符号があるのはなぜでしょうか。

これは、平行四辺形の面積に「向き」の情報を加えているからです。

反時計回り：正

\(\operatorname{cross}(a,b)=+S\)

時計回り：負

\(\operatorname{cross}(a,b)=-S\)

上の図では、\(\boldsymbol a\) を \(\boldsymbol b\) に重ねるために、180°未満の回転を考えています。

- 反時計回りに回転するなら、外積は正。
    
- 時計回りに回転するなら、外積は負。
    
- 平行なら、外積は0。
    

したがって外積は、「面積」と「回転方向」という2つの情報を同時に持っています。

ここで重要なのが、引数の順序です。

\[ \boxed{ \operatorname{cross}(\boldsymbol a,\boldsymbol b) =-\operatorname{cross}(\boldsymbol b,\boldsymbol a) } \]

ベクトルを交換すると、回転の向きが逆転するため、符号も逆転します。

## 4. なぜ「2つのベクトルから新たなベクトルが得られる」と説明されるのか？

ここまでは2次元の外積を、単なる数値として説明しました。

しかし、本来の外積は3次元空間における演算です。

\[ \boldsymbol a=(a_x,a_y,a_z),\quad \boldsymbol b=(b_x,b_y,b_z) \]

に対して、

\[ \boldsymbol a\times\boldsymbol b= \begin{pmatrix} a_yb_z-a_zb_y\\ a_zb_x-a_xb_z\\ a_xb_y-a_yb_x \end{pmatrix} \]

と定義されます。

この結果は、以下の特徴を持つベクトルになります。

1. 長さが、2つのベクトルが作る平行四辺形の面積に等しい。
    
2. 方向が、2つのベクトルの両方に垂直である。
    
3. 向きは右手系の規則（右手の法則）に従う。

例えば、\(xy\) 平面上の2つのベクトルであれば、外積は必ず \(z\) 軸方向を向きます。

\[ (a_x,a_y,0)\times(b_x,b_y,0) = (0,0,a_xb_y-a_yb_x) \]

## 5. 競プロで特に役立つ幾何的解釈

以上を理解すると、外積を使った幾何アルゴリズムはかなり自然に導けます。

### ① 3点の位置関係（CCW判定）

3点 \(A,B,C\) が与えられたとき、

\[ \operatorname{cross}(B-A,C-A) \]

を計算します。

これにより、\(A\to B\) という進行方向に対して、\(C\) が左側にあるか、右側にあるかを判定できます。

左側：外積 ＞ 0

右側：外積 ＜ 0

直線の左側・右側を判定できるので、今回のABCのような半平面の判定にも利用できます。

さらに、凸包を求める Andrew's Algorithm などでも、このCCW判定が基本操作となります。

### ② 三角形の面積

3点 \(A,B,C\) が作る三角形の面積は、

\[ \boxed{ S=\frac12|\operatorname{cross}(B-A,C-A)| } \]

です。

これは、三角形の面積が同じ底辺と高さを持つ平行四辺形の半分になるからです。

### ③ 線分の交差判定

線分 \(AB\) と線分 \(CD\) が互いに交差するかどうかも、外積で調べられます。

例えば、真に交差する場合は、\(C,D\) が直線 \(AB\) の異なる側に存在し、同時に \(A,B\) が直線 \(CD\) の異なる側に存在します。

これも外積の符号によって判定できます（端点が一致する場合や共線の場合は別途処理が必要です）。

## 6. 内積との対比で理解する

最後に、よく使う内積との違いを整理します。

||内積 \(\boldsymbol a\cdot\boldsymbol b\)|2次元の外積 \(\operatorname{cross}(a,b)\)|
|---|---|---|
|定義|\(a_xb_x+a_yb_y\)|\(a_xb_y-a_yb_x\)|
|三角関数|\(\lvert a\rvert\lvert b\rvert\cos\theta\)|\(\lvert a\rvert\lvert b\rvert\sin\theta\)（有向角）|
|幾何的意味|一方への射影の大きさ|符号付き平行四辺形の面積|
|正負の意味|同方向寄りか、逆方向寄りか|反時計回りか、時計回りか|
|0になる条件|直交|平行|

特に重要なのは、内積と外積は、それぞれ「平行方向の成分」と「垂直方向の成分」に対応しているということです。

\[ \underbrace{\boldsymbol a\cdot\boldsymbol b}_{\text{平行方向}} =|\boldsymbol a||\boldsymbol b|\cos\theta \]

\[ \underbrace{\operatorname{cross}(\boldsymbol a,\boldsymbol b)}_{\text{垂直方向}} =|\boldsymbol a||\boldsymbol b|\sin\theta \]

これを覚えておくと、角度を直接計算せずに、内積・外積だけで多くの幾何的な判定ができることがわかります。

競プロにおいては、外積を「ベクトルを生成する演算」として意識する必要はほとんどありません。まずは 「外積＝符号付き面積＝左右判定」 という3つの意味が同じ値から得られることを理解しておくのが有用だと思います。

## 1. 傾きの差から外積を導く

まず、2点（位置ベクトル）

\[ A=(x_a,y_a),\qquad B=(x_b,y_b) \]

を考えます。

仮に両方とも第1象限にあるとしましょう。

この場合、傾き \(y/x\) は偏角 \(\theta\) が大きくなるほど大きくなります。

したがって、

\[ \theta_a<\theta_b \iff \frac{y_a}{x_a}<\frac{y_b}{x_b} \]

です。

両方とも \(x_a,x_b>0\) なので、分母を払うと、

\[ \begin{aligned} \frac{y_a}{x_a}&<\frac{y_b}{x_b}\\ y_ax_b&<y_bx_a\\ 0&<x_ay_b-x_by_a \end{aligned} \]

となります。

つまり、

\[ \boxed{\theta_a<\theta_b \iff \operatorname{cross}(A,B)>0} \]

が導けました。

これはまさに指摘されている考え方です。

ただし、この議論では \(x_a,x_b>0\) を仮定しています。片方の \(x\) が負になれば、不等号の向きを考慮する必要があります。また \(x=0\) では傾きそのものが定義できません。

そのため、傾きの差は外積を理解する一つの入口として有効ですが、より一般的な説明には別の方法を使いたいところです。

## 2. 外積と角度差の関係

それぞれの点の偏角を \(\theta_a,\theta_b\) とします。

極座標で表現すると、

\[ \begin{aligned} A&=(r_a\cos\theta_a,r_a\sin\theta_a)\\ B&=(r_b\cos\theta_b,r_b\sin\theta_b) \end{aligned} \]

です。

ここで、外積を計算します。

\[ \begin{aligned} \operatorname{cross}(A,B) &=x_ay_b-y_ax_b\\ &=r_ar_b(\cos\theta_a\sin\theta_b -\sin\theta_a\cos\theta_b) \end{aligned} \]

三角関数の加法定理

\[ \sin(\beta-\alpha) =\sin\beta\cos\alpha-\cos\beta\sin\alpha \]

を使うと、

\[ \boxed{ \operatorname{cross}(A,B) =r_ar_b\sin(\theta_b-\theta_a) } \]

が得られます。

これが、外積で偏角の大小関係を判定できる数学的な原理です。

\(r_a,r_b>0\) なので、外積の符号は \(\sin(\theta_b-\theta_a)\) の符号だけで決まります。

具体的には、

\[ \begin{cases} \operatorname{cross}(A,B)>0 &\iff \sin(\theta_b-\theta_a)>0\\ \operatorname{cross}(A,B)<0 &\iff \sin(\theta_b-\theta_a)<0 \end{cases} \]

となります。

## 3. では、なぜ半平面に分ける必要があるのか？

ここが偏角ソートにおける最も重要な点です。

外積が正であることは、必ずしも \(\theta_a<\theta_b\) を意味しません。

例えば、

\[ \theta_a=300^\circ,\qquad\theta_b=60^\circ \]

としましょう。

このとき、

\[ \theta_b-\theta_a=-240^\circ \]

なので、

\[ \sin(-240^\circ)>0 \]

です。

つまり、外積は正になりますが、角度の大小関係は

\[ 300^\circ>60^\circ \]

です。

これは、外積の符号が角度差を360°周期で扱っているために起こります。

そこで、角度差が必ず180°未満になるように、比較する範囲を制限するわけです。

上半平面は0°〜180°、下半平面は180°〜360°に対応する

例えば、上半平面に属する2点なら、

\[ 0\le\theta_a,\theta_b<\pi \]

なので、

\[ -\pi<\theta_b-\theta_a<\pi \]

です。

この範囲では、\(\sin x\) の符号と \(x\) の符号が一致します。

したがって、

\[ \boxed{ \theta_a<\theta_b \iff \operatorname{cross}(A,B)>0 } \]

が正しく成立します。

下半平面についても同様です。

なお、ここでいう上半平面・下半平面には境界の扱いが必要なので、実装上は

\[ \operatorname{half}(x,y)= \begin{cases} 0 & y>0\lor(y=0\land x>0)\\ 1 & \text{otherwise} \end{cases} \]

と定義します。

これは、正の \(x\) 軸を0°、負の \(x\) 軸を180°側として扱うためです。

## 4. 偏角ソートの比較関数が成立する仕組み

以上から、任意の2点 \(A,B\) の大小関係は次のように判定できます。

1. 異なる半平面にいるなら、上半平面の点を先にする。
    
2. 同じ半平面にいるなら、\(\operatorname{cross}(A,B)>0\) の場合に \(A\) を先にする。
    

C++では、次のように書けます。

```
struct Point {
    long long x, y;
};

int half(const Point& p) {
    return (p.y > 0 || (p.y == 0 && p.x > 0)) ? 0 : 1;
}

long long cross(const Point& a, const Point& b) {
    return a.x * b.y - a.y * b.x;
}

bool cmp(const Point& a, const Point& b) {
    int ha = half(a), hb = half(b);

    if (ha != hb) return ha < hb;

    return cross(a, b) > 0;
}
```

これで、偏角を \([0,2\pi)\) に正規化した昇順ソートと同じ順序になります。

ただし、原点 \((0,0)\) は偏角が定義されないため除外する必要があります。また、同じ方向を向く点同士は同値として扱われます。距離などでさらに順序を付けたいなら、その場合の比較条件を追加します。

## 5. もう一つの直感的な理解：回転方向を比較している

外積の式を三角関数から導く方法は数学的には明快ですが、競プロの実装を考える際には、さらに単純な捉え方ができます。

外積の符号は、ベクトル \(A\) からベクトル \(B\) への回転方向を教えてくれる。

- `cross(A,B) > 0`：AからBへ、反時計回りに180°未満で到達できる。
    
- `cross(A,B) < 0`：AからBへ、時計回りに180°未満で到達できる。
    
- `cross(A,B) == 0`：平行（同方向または反対方向）。
    

偏角ソートでは、まず全体を2つの半平面に分けることで、比較対象の角度差が180°未満になることを保証します。

そのうえで、「AからBへ反時計回りに回転するならAの方が偏角が小さい」と判定しているわけです。

したがって、比較関数の

```
return cross(a, b) > 0;
```

は、実質的には

```
return angle(a) < angle(b);
```

に相当しています。

## 6. 傾きの差と外積、どちらで理解するべきか？

両方とも有用ですが、私は次のように整理するのがよいと思います。

傾きの差による理解

\[ \frac{y_b}{x_b}-\frac{y_a}{x_a} =\frac{x_ay_b-x_by_a}{x_ax_b} \]

この式から、外積は「傾きの大小比較に使える式」であることがわかります。

ただし、分母 \(x_ax_b\) の符号やゼロ除算に注意する必要があるので、適用できる範囲は限定されます。

外積による理解

\[ \operatorname{cross}(A,B) =|A||B|\sin(\theta_b-\theta_a) \]

この式なら、\(x=0\) を特別扱いする必要がありません。

外積の符号が角度差の正負に対応することを、直接説明できます。

そのため、競プロで使う際には、後者を基本として理解する方がおすすめです。

結局、偏角ソートの原理は次の一文に集約できます。

\[ \boxed{ \text{角度差を180°未満に制限すれば、外積の符号で角度の大小を判定できる。} } \]

これが、半平面分類と外積を組み合わせる理由です。
